## Template update

Run from `pool-app` with the verified target environment configured:

```sh
npx tsx scripts/add-reinspection-summary.ts --target VERIFIED_TEMPLATE_ID
npx tsx scripts/add-reinspection-summary.ts --target VERIFIED_TEMPLATE_ID --apply --backup-dir PRIVATE_BACKUP_DIRECTORY
```

The first command is read-only. The apply command writes a private JSON backup
before changing the one selected template. It compares the original fields in
the update condition, refusing to overwrite concurrent edits. It preserves every
existing field and appends one optional textarea. Re-running is a no-op; conflicting
Q109 definitions or an unexpected template are rejected. Keep the backup outside
version control and retain it before making the production change.
